中文 FAQ

Tracejar 是什么？

一个只属于你的私人时间轴/日记。文字、照片、视频、语音、心情、标签，都留在你的设备和你自己的私人 iCloud 里。没有服务器、不被分析、没有广告。

我的数据会被你们看到吗？

不会。App 没有任何服务器。开启 iCloud 同步时，数据进的是你的 Apple ID 私有 iCloud 数据库，开发者没有访问权限。

怎么开启面容 ID / 触控 ID 锁？

设置 → 面容 ID 与伪装（支援触控 ID 的设备显示 触控 ID 与伪装）→ 打开当前设备支持的生物识别锁。首次开启时会让你设置一个 App 锁密码（用于日后从伪装模式切回真实数据）。这个密码与私密相册密码互相独立。

什么是伪装（Decoy）模式？

开启后，如果生物识别失败或被取消，App 不会把你锁在门外，而是显示一套平平无奇的假记录——别人随手翻看时看不出这里有敏感内容。

怎么从伪装模式切回真实数据？

在时间轴页面长按左上角的设置图标约 0.8 秒（标准皮肤是齿轮，ASCII 皮肤是 [≡]），弹出密码框后：

  • 输入你的 App 锁密码；或
  • 点当前设备显示的生物识别解锁按钮——你本人通过 Face ID / Touch ID 即可回到真实数据。

我忘了 App 锁密码怎么办？

用设备支持的 Face ID / Touch ID 就能回到真实数据（见上）。密码以「随机盐 + SHA-256」存在设备 Keychain 里，我们不存明文，无法帮你找回。

私密相册使用另一组密码：忘了相册密码就永远打不开，任何人都没办法。如果你在某台设备上已经开启相册生物识别并打开过相册，那台设备还能继续通过本机生物识别打开，可以趁早把需要的照片存出来。

私密相册是什么？

设置 → 私密相册。第一次进入时单独设置相册密码；放进去的照片会先在设备上加密，再保存、经你自己的 iCloud 同步到其它设备，不会出现在时间轴里。加密保存成功后，App 会请求 iOS 删除本次选中的系统相册原图；iOS 会让你确认，删除的图片会在「最近删除」里保留 30 天。若没有授予完整相册权限，原图会保留。相册右上角齿轮里可以修改相册密码，并单独选择是否允许本机生物识别（Face ID / Touch ID）解锁。修改 App 锁密码不会改变相册密码，反过来也一样。切到别的 App 就自动锁上。

假记录会同步到 iCloud 吗？

不会。伪装数据只在本机，运行时用内存数据库，关闭 App 即清空。

位置为什么没自动记录？

位置默认是关闭的。 需要的话去 设置 → 打开「自动定位」，之后新建记录才会标记当前位置。

怎么导出我的记录？

设置 → 导出 CSV。会生成一个表格文件，通过系统分享面板由你决定存到哪。（照片/视频/语音不含在内，只记数量。）

iCloud 同步怎么用？

设置 → 打开「iCloud 同步」（默认开）。换手机后，用同一个 Apple ID 登录并安装 Tracejar，数据会自动回来。修改这个开关需要重启 App 才生效。

界面有两套皮肤？

是的。设置 → 界面 → 可在「标准」和「ASCII 终端」之间切换。功能完全一样，只是外观不同。

删除数据

在 App 内删除记录即可；删除 App 会移除本机数据；iCloud 副本可在 系统设置 → Apple ID → iCloud 里管理。

English FAQ

What is Tracejar?

A private timeline/journal that's yours alone. Text, photos, videos, voice notes, mood, tags — all stored on your device and in your own private iCloud. No servers, no analytics, no ads.

Can you see my data?

No. The app has no servers. With iCloud Sync on, data goes to your Apple ID's private iCloud database, which the developer cannot access.

How do I enable the Face ID or Touch ID lock?

Settings → Face ID Lock & Decoy on Face ID devices, or Touch ID Lock & Decoy on Touch ID devices → turn on the biometric lock shown for this device. The first time, you'll be asked to set an App Lock passcode (used later to return from Decoy Mode to your real data). This is separate from the Private Album passcode.

What is Decoy Mode?

When enabled, if biometric authentication fails or is cancelled, the app doesn't lock you out — it shows an ordinary-looking set of fake entries, so someone glancing at your phone can't tell there's sensitive content.

How do I get back to my real data from Decoy Mode?

On the timeline, long-press the settings icon (top-left) for ~0.8 s (a gear in the standard skin, [≡] in the ASCII skin). When the passcode prompt appears:

  • enter your App Lock passcode; or
  • tap the biometric unlock button shown for your device — your own Face ID or Touch ID brings back the real data.

I forgot my App Lock passcode.

Use the Face ID or Touch ID available on your device to return to your real data (see above). The App Lock passcode is stored as a random salt + SHA-256 hash in the device Keychain; we never store it in plain text and cannot recover it. The Private Album uses a different passcode.

The Private Album uses a separate passcode: if you forget it its photos can never be opened by anyone. If you've enabled album biometrics and opened the Private Album on a device, that device can still use its biometric unlock, so save any photos you need from there.

What is the Private Album?

Settings → Private Album. The first time, set a separate album passcode. Photos you add are encrypted on your device before they're saved and synced through your own iCloud; they never appear on your timeline. After encrypted storage succeeds, Tracejar asks iOS to remove the selected originals from Photos. iOS asks you to confirm, and deleted images remain in Recently Deleted for 30 days. If full Photos access is unavailable, the originals stay. Open the gear in the album to change its passcode and independently choose whether Face ID or Touch ID can unlock it on this device. Changing either the album passcode or the App Lock passcode does not change the other. It locks when you switch to another app. If you forget the album passcode, its photos can never be opened by anyone.

Do the fake entries sync to iCloud?

No. Decoy data stays on-device, lives in an in-memory database at runtime, and is cleared when the app closes.

Why isn't my location being recorded?

Location is off by default. Turn on Settings → "Attach location to new entries" if you want new entries tagged.

How do I export my entries?

Settings → Export as CSV. A spreadsheet file is generated and shared wherever you choose. (Photos/videos/audio aren't included — only their counts.)

How does iCloud Sync work?

Settings → turn on "iCloud Sync" (on by default). On a new phone, sign in with the same Apple ID and install Tracejar; your data returns automatically. Changing this toggle takes effect after you restart the app.

There are two different looks?

Yes. Settings → UI → switch between "Standard" and "ASCII terminal". Same features, different skin.

Deleting data

Delete entries in-app; deleting the app removes local data; the iCloud copy can be managed in iOS Settings → Apple ID → iCloud.
